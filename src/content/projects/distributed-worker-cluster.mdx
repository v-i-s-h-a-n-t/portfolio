## Overview

This Java RMI project runs jobs across registered worker nodes. Workers elect a coordinator to manage distributed job execution.

## Objectives and requirements

- Register worker processes with unique IDs through a bootstrap service and connect each new worker to an active peer.
- Submit concurrent `MAX`, `PRIMECOUNT`, and `PRIMESUM` jobs from a client GUI, using manual input or CSV files.
- Run the bootstrap service on the default RMI port, 1099, or a configured port.

## Architecture

The bootstrap service creates the RMI registry and tracks active workers. New workers register with unique IDs and connect to a random active peer. Workers elect a coordinator through flooding and convergecast; a client discovers workers through the bootstrap service and submits jobs to the coordinator. Work is partitioned across workers, then validated partial results are aggregated for the client.

## My contributions
