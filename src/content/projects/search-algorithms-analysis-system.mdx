## Overview

This Java desktop application compares search algorithms using ArrayList and LinkedList data, then visualizes empirical analysis and algorithm races.

## Objectives and requirements

- Compare search algorithms over ArrayList and LinkedList data.
- Present empirical comparisons, algorithm races, and worst-case complexity charts.

## Architecture

The Java Swing application runs the search algorithms and empirical tests. OpenCSV supports CSV input, and JFreeChart renders the comparison and complexity charts.
