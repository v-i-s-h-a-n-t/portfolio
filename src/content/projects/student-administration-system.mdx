## Overview

This full-stack student administration system manages student and staff records, classes, enrollment, assessments, marks, and reports. Its documented stack combines a Next.js frontend with a Spring Boot backend and PostgreSQL database.

## Objectives and requirements

- Manage student and staff records, classes, enrollment, assessments, and marks.
- Generate reports and restrict system functions by user role using JWT authentication.

## Architecture

The documented design pairs a Next.js and TypeScript frontend with a Spring Boot API. The backend uses PostgreSQL for application data and JWT authentication for role-based access.
